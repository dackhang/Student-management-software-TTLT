# 🎓 Student Management Software - TTLT

> 📘 Phần mềm quản lý sinh viên sử dụng C# WinForms

## 📌 Giới thiệu
Ứng dụng giúp quản lý thông tin sinh viên và lớp học, hỗ trợ nhập liệu, tìm kiếm và thống kê đơn giản. Giao diện thiết kế theo kiểu WinForms truyền thống, dễ sử dụng, phù hợp cho cán bộ quản lý hoặc giáo vụ trong trường học.

## 🛠️ Công nghệ sử dụng
- Ngôn ngữ: C# (WinForms)
- Cơ sở dữ liệu: SQL Server
- IDE: Visual Studio 2019/2022
- Giao tiếp CSDL: ADO.NET

## 🚀 Tính năng chính
- Thêm / sửa / xóa sinh viên.
- Quản lý các thông tin như: mã SV, tên, ngày sinh, địa chỉ, số điện thoại, mã lớp...
- Lọc sinh viên theo mã lớp (ComboBox).
- Hiển thị dữ liệu bằng DataGridView.
- Kiểm tra đầu vào, validate dữ liệu.
- Kết nối cơ sở dữ liệu SQL Server và thao tác CRUD.
